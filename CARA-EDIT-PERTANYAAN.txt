========================================
CARA CUSTOM PERTANYAAN
========================================

Ada 4 file JSON yang bisa kamu edit:

1. questions-tod.json
   → Truth or Dare
   → Struktur: soft / medium / spicy → masing-masing punya "truth" dan "dare" (array string)

2. questions-knowme.json
   → How Well Do You Know Me
   → Struktur: array string biasa
   → Game akan acak dan ambil 7 pertanyaan

3. questions-lovematch.json
   → Love Match
   → Struktur: array object { "q": "pertanyaan", "opts": ["opsi1", "opsi2", ...] }

4. categories-words.json
   → Guess Same Words
   → Struktur: array object { "name": "Nama Kategori", "icon": "Emoji", "hint": "Petunjuk" }
   → Contoh:
     {
       "name": "Makanan Penutup",
       "icon": "🍰",
       "hint": "Camilan manis favorit kalian!"
     }
